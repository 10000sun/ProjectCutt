# ProjectCutt

JSP로 만든 예약 웹 서비스 학습 프로젝트입니다. 일반 회원·업체 회원 가입과 로그인, 마이페이지, 업체 메뉴 관리, 예약, 공지사항·문의·리뷰 게시판 기능이 `project/` 아래에 들어 있습니다. `ProjectCutt.war`는 빌드된 배포 파일입니다.

- 기술: JSP/Servlet, JSTL, MySQL(JDBC), HTML/CSS/JavaScript, 도로명주소 검색 팝업(juso)
- 목적: 학습 (2023년 작성)
- 실행 시 `project/db/dbconn.jsp`의 DB 접속 정보와 juso 팝업의 `confmKey`를 본인 값으로 바꿔야 합니다 (저장소에는 샘플 값만 남겨 두었습니다).
- 상태: 더 이상 유지보수하지 않는 **아카이브** 저장소입니다.
